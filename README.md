## 🛠️ Como Adicionar um Novo Print

1. Salve seu print com formato `.png` ou `.jpg` na subpasta correspondente:
   - Exemplo: `tarefas/tarefa-01/prints/git-version.png`
2. No VS Code ou terminal:
   ```bash
   git add .
   git commit -m "docs(tarefa-01): adiciona prints de comprovação"
   git push origin main
   ```
3. A imagem será renderizada automaticamente na visualização do GitHub!
